# 开天一念 · 微信小程序原型

## 导入与运行

使用微信开发者工具打开仓库根目录 `roguelikeGame`。项目配置使用 `touristappid` 占位；如需真机预览或发布，请在 `project.config.json` 中填入自己的小程序 AppID。

当前原型支持左下半透明摇杆移动、范围内自动攻击、敌人和 Boss 波次、灵气升级三选一、地火水附魔、四象关卡推进、记忆提示、天道终战与结局。攻击范围以人物周围淡圈显示；升级选中后立即生效并关闭弹窗。所有游戏逻辑运行在微信小程序原生页面中，无外部依赖。

界面为固定横屏，升级三选一横向排列。游戏右上角「设置」可暂停/继续战斗、调整音效开关与音量、震动及操作提示，也可确认退出本局返回主菜单。设置保存在本机，退出与重新开始不会重置偏好。已接入攻击、受击、升级与结局音效。

人物已接入待机、移动、普攻、受击、升级觉醒和神念消散六组四向动画（共 144 帧）。移动连续且随行进方向转身，攻击时朝向目标，收招后恢复行进朝向；没有遁光或元素施法按钮。动作源与离线预览见 [人物动作说明](art/pangu-actions/README.md)。

## 当前原型边界

这是用于验证核心循环的可玩原型：关卡由同一竞技场按主题和 Boss 轮换呈现；四段记忆目前以短文本闪回展示，五境场景、四象与天道角色、升级图标及结局绘景已接入；分镜 CG、骨骼动画和进度存档尚未接入。首次运行时请在微信开发者工具中检查画面比例与触控手感。
