# 开天一念 · 微信小程序原型

## 导入与运行

使用微信开发者工具打开仓库根目录 `roguelikeGame`。项目配置使用 `touristappid` 占位；如需真机预览或发布，请在 `project.config.json` 中填入自己的小程序 AppID。

当前原型支持触屏拖动移动、自动攻击、敌人和 Boss 波次、灵气升级三选一、地火水附魔、四象关卡推进、记忆提示、天道终战与结局。所有游戏逻辑运行在微信小程序原生页面中，无外部依赖。

人物已接入待机、移动、普攻、受击、升级觉醒和神念消散六组四向动画（共 144 帧）。移动连续且随行进方向转身，攻击时朝向目标，收招后恢复行进朝向；没有遁光或元素施法按钮。动作源与离线预览见 [人物动作说明](art/pangu-actions/README.md)。

## 当前原型边界

这是用于验证核心循环的可玩原型：关卡由同一竞技场按主题和 Boss 轮换呈现；四段记忆目前以短文本闪回展示，五境场景、四象与天道角色、升级图标及结局绘景已接入；分镜 CG、骨骼动画、音效和保存档案尚未接入。首次运行时请在微信开发者工具中检查画面比例与触控手感。
