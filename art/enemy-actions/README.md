# 小怪造型与关键动作

运行图集：`cocos-project/assets/game-content/images/enemy-actions.png`。
768×512，四行六列，每格 128×128，透明索引 PNG，约 85 KiB。

| 行（从零开始） | 类型 | 轮廓 | 六列内容 |
| --- | --- | --- | --- |
| 0 | 混沌游灵 | 墨青烟团、琥珀双眼、飘尾 | 六帧漂浮循环 |
| 1 | 蚀法祭徒 | 瘦高兜帽、月牙法杖、青白符印 | 两帧待机、两帧蓄力、释放、收招 |
| 2 | 裂界行者 | 低伏兽身、前突独角、青铜甲片 | 两帧移动、蓄势、冲刺、制动、收招 |
| 3 | 圣人执念 | 宽肩石臂、三叉石冠、紫金核心 | 两帧待机、两帧蓄力、释放、收招 |

造型为统一水墨矿彩风格的 AI 生成素材。经图像工具去除背景后，离线缩小并量化为运行图集；不是在运行时生成动画。

动画状态源是 `game/core/enemy-animation.js`，Cocos 根据战斗状态选择图集帧。动作不改变预警时间、攻击判定或怪物数值。冻结控制和游戏暂停停止动作推进；冲锋朝向按已锁定的冲锋路线镜像，避免玩家绕后时怪物突然转身。

Boss 的独立动作和法术表现见 [Boss 动作](../boss-actions/README.md)。受击形变、伤害数字和击杀碎光仍由程序表现。原有静态游灵图保留于素材库，运行加载改为新图集。

源图由图像生成工具制作，工作区原始文件：`/workspace/generated_images/exec-bbc466b4-cd5c-4719-8054-af64a237603f.png`。原始文件不进入小游戏包。图集压缩命令（需要 ImageMagick 7）：

```sh
magick source.png -resize 768x512 -dither None -colors 192 PNG8:enemy-actions.png
```
