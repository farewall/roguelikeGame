# 混沌众生 · 运行素材

本轮按已确认的全身设定重建四类小怪、四象法相和天道化身。它们是混沌重新凝形的血肉，不是天地毁灭后幸存的旧生灵。弱怪无甲小体、吞灵囊兽宽腹、裂界奔兽长肢、镇劫重兽厚胸骨盾，大小与轮廓区分强弱和攻击方式。

- 生物六列：站立、移动、蓄势、攻击、受击、形体失稳。受击姿态优先，预警与攻击姿态由真实危险区时间驱动。

素材由 imagegen 依照已确认的设定图制作，再进行机械缩放和 保留渐变透明度的调色板压缩。普通怪图集约 197 KiB，新首领与雾气图集约 388 KiB；使用真实 alpha 透明背景。高分辨率生成源保留在本次工作区的 `generated_images`，不作为微信运行资源加载。

## 生命周期

生产刷怪从低伏雾旋中凝形（普通 0.3 秒，精英 0.5 秒，首领 0.8 秒），期间不攻击、不触碰伤害、不吸收武器命中。成形后沿原机制战斗，命中时切换受击姿态并作短暂形变和后坐。

致死时立即移除碰撞和攻击，奖励只结算一次；独立残影按比例播放：前 18% 受击失衡、18–64% 裂纹失稳并逐渐淡出、12% 起雾气扩散、末段只留低伏涡流与零星灵气。没有尸体、固体碎块或血池。时长：弱怪 0.65 秒、普通 0.9 秒、精英 1.2 秒、首领 1.8 秒。残影最多 28 个，并优先保留首领。

首领散尽后才弹出记忆或最终结算。设置、切后台冻结整个演出；演出中移动和技能输入受阻。新局和换境清空残影。图鉴保留原存档 ID，仅更新名称与描述。

## 验证

核心测试覆盖凝形交互边界、单次奖励、残影到期与数量上限、暂停及后台恢复、首领演出与结算顺序。Creator Web 导出测试在 844×390 与 667×320 下截图验证九种形体的凝形、实体、受击、失稳、化雾、回归六个状态，并保留实际战斗、技能、升级、记忆、存档与首领危险区验证。
