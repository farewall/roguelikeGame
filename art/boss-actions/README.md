# Boss 动作与法术表现

当前动作、实体攻击和二阶段暴怒以 [Boss 战斗规则](../../docs/BOSS-COMBAT.md) 为准。地面不再绘制伤害范围的圈、矩形、箭头；法术纹理用于真正释放的水浪、火焰、吐息与爪痕。蓄势与收招由生物本身表达。

`cocos-project/assets/game-content/images/boss-actions.png`：768×768，六行六列，每格128×128，透明索引PNG，约173KiB。

前五行依次为青龙、白虎、朱雀、玄武、天道；每行六帧：待机A、待机B、蓄力A、蓄力B、释放、收招。最后一行是火羽、法阵、符光、藤蔓、水浪、爪痕六种法术切片。

Boss 保持原有青金龙、白虎、赤金凤、玄甲龟蛇、白金紫袍天道的造型，动作按各自的盘卷、扑杀、振翼、缩甲和结印表现。白虎沿已锁定的扑杀路线镜像；在危险区实际生效的短窗口切入释放动作。统一动作时钟来自战斗推进，暂停和冰封停止动作。

`HazardVfx.ts` 用纹理和有限的几何效果替代地面的中文占位符：

- 火羽：预警期间下落，生效时出现命中扩散、持续火焰和余烬。
- 精英法阵：预警聚能，生效时旋转阵纹、核心光环与微粒。
- 祭徒符光：方向预警后瞬间点亮整条光束，匹配现有直线伤害；移动彗光作为束内细节，不把现有光束伤害误表现为慢速弹丸。
- 冲锋及白虎扑杀：方向箭头、实际移动的兽身、爪痕拖尾和亮起的攻击路径。
- 青龙藤蔓：萌芽预警和生效后的多向藤刺。
- 玄武潮汐：保留安全内圈，环带内出现水浪与扩散纹理。
- 天道封锁：沿边界生成连续旋转阵印及秩序光柱。

碰撞使用圆、环、线段和扫尾弧等内部几何，但这些几何不作为界面预警绘制。根脉、浪头与冲锋碰撞跟随可见实体推进。视觉时间读取战斗状态，不使用独立定时器。法术节点按攻击 ID 复用和清理，没有每帧新建粒子系统。友方区域使用更低亮度。
