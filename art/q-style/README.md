# Q 版试玩源图

这批原创图用于《开天一念》的首页、盘古、三件至宝、四类小怪、五位首领和五境地形。源图不进入正式小游戏包。裁切坐标位于 `crops.json`，以源图左上角为原点，右下坐标不含端点。

盘古与三件至宝采用木刻线条、朱砂、骨白与墨蓝色块。盘古的 `hero-run.png` 补充正面、背面和侧面的落脚与换步姿态，左向沿用侧面镜像。首页选宝卡复用战斗里的法宝造型。

古榕青涧使用 `first-realm-ground.jpg` 的浅砂地面与 `first-realm-props.png` 的松、泉、石。五境共用现有地面和地物图集，各自的地形和碰撞由关卡数据驱动。

在仓库根目录使用 `npm run prepare:art` 重建图集。输出复用运行时原有帧槽及落脚基线，`art/catalog.json` 记录包归属和运行尺寸。
