# 白虎·庚金猎主

白虎以抢位、双爪和腾空重扑构成一次追猎。它不沿用小怪的直线冲锋，也不绘制攻击范围标记。

## 动作与应对

| 动作 | 行为 | 玩家应对 |
| --- | --- | --- |
| 猎步截路 | 起手采样近期移动方向，蓄势 0.42 秒，横步 0.36 秒；目的地锁定，移动本身不造成伤害 | 转向可以骗过预判；留意下一次压肩或抬爪 |
| 裂金双爪 | 低肩 0.68 秒后横爪，抬另一只爪 0.56 秒后下劈；每一爪分别锁定方向 | 离开爪尖，或绕到另一侧；爪痕只在出手后出现 |
| 断岳扑杀 | 伏身 0.92 秒，腾空 0.48 秒，沿锁定路线落下；重扑最大 570 UI 单位 | 伏身后横移，起跳后不会拐弯；可把骨柱放在扑击路线上 |
| 骨柱破势 | 撞击路线上的第一处实体若是完整骨柱，打碎高处，前爪卡地并挣扎 2.1 秒 | 抓住易伤 35% 的输出窗口；不要求利用骨柱才能获胜 |
| 落地追猎 | 半血暴怒后，落地停顿、回望，再按距离固定选择追扑或回身横剪 | 追扑有新的 0.82 秒伏身并重新瞄准；横剪有 0.72 秒扭腰抬爪；每轮最多追加一次，然后收招 |

起手时间另含一帧的释放对齐，保证实际伤害不先于出手姿态。遗迹庇护仍为每次扑击增加 0.18 秒起手。普通收招为 1.2 秒，扑空同样露出易伤；命中时仍有停顿但不自动易伤。每轮结束另留 1.1 秒正常走位。

## 地形和性能

第二关预先将六处既有障碍物换成骨柱，覆盖三个区域。普通追踪沿已有寻路图绕行，扑击沿固定路线被第一处地形截停。撞碎后保留同一大小的可见基座和碰撞占地，只移除高处遮挡，因此不用在首领登场或撞击时重建导航。骨柱状态会写入安全存档；旧存档没有骨柱字段时按完整骨柱恢复。存档继续清理旧攻击，从中立姿态恢复。

没有命中停帧。冲击使用短暂的灰尘和骨片；镜头平滑偏向白虎上半身，摇杆和 HUD 不随动作摇动。素材在进入游戏时预载。

## 实体素材

`art/white-tiger/design.png` 保存确认过的六格设计。`poses.png` 是十二个主体姿态，`rear.png` 补齐背向的伏身、飞扑、落地与横爪，`pillars.png` 包含完整骨柱、同占地的基座与骨片。素材由图像生成工具按设计制作，背景透明，主体不靠发光圆环表达。

运行 `python tools/prepare-white-tiger.py` 可复现两个运行时图集：十六个 192 像素白虎帧、三个 192 像素骨柱帧。统一足底基准，基座和完整骨柱使用同一缩放比例。向上攻击使用背向实体，横向只镜像，不旋转整只虎来冒充朝向。

图集共约 162 KiB。将运行时已由持宝动作替代的旧空手 `pangu/move.png` 移至 `art/pangu-reference` 保存原图，保持原有 3.5 MiB 内容预算。主角持宝移动图集和摇杆没有删除。

## 验证

`tools/white-tiger.test.cjs` 检查不可变的抢位、双爪实际扫掠判定、逐次瞄准、二阶段分支锁定、强制收招、真实撞柱、基座碰撞和导航保持、存档兼容、冰冻与半血取消。原有普通血量通关测试继续覆盖三种武器。

`tools/cocos/preview.test.cjs` 在正式 Creator 导出中驱动实际追猎时钟，截取两种手机尺寸下的横步、双爪、腾空和回身动作，校验独立纹理与控件；并保留五位首领的暴怒和暂停恢复检查。
