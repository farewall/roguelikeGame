# Boss 动作、暴怒与实体攻击

所有伤害从可见生物的动作起手。战斗画面不绘制地面预警圈、矩形、箭头、常驻射程圈或蓄力状态环；保留真实传播的钟鸣，以及藤蔓、陨火、海浪、吐息和爪痕。精英的震击从落爪处扩散，地图氛围不再独立生成无施法者的伤害。

## 五位首领

| 首领 | 动作与攻击 | 暴怒后的变化 | 反击机会 |
| --- | --- | --- | --- |
| 青龙 | 盘身 1.05 秒后伸出三条分叉根脉，0.95 秒长到末端；随后转向、蓄势并甩尾 | 第二组根脉转过一个角度，前一组退去后接替；再出甩尾 | 藤蔓间隙、甩尾结束后的 1.25 秒收招 |
| 白虎 | 伏身 0.95 秒后直线扑杀，虎身经过处结算伤害 | 第一扑落地后停稳 0.1 秒，重新采样主角当前位置；转身伏低 0.78 秒后第二扑 | 连扑结束后 1.55 秒收招；整套扑空易伤 35% |
| 朱雀 | 振翼逐次发出三颗陨火，每隔 0.32 秒单独锁定；余烬留下 2.2 秒火地，随后扇翼推出带缺口的火浪 | 每轮五颗陨火，火浪推进略快；暴怒演出清理旧火区 | 从熄灭的焦痕回转、穿过 170 UI 单位的火浪缺口，收翼后输出 |
| 玄武 | 缩甲聚水 1.15 秒，以本体中心向外发出实体海浪，浪头从 66 推进至 340 UI 单位 | 三道向外海浪每隔 1 秒起手，最大推进至 390，缺口轻微错开 | 穿过浪面缺口、绕向亮起的甲片核心；收招开甲 1.55 秒 |
| 天道 | 法环聚能后降下敕令，随后轮换「根脉→追扑」与「陨火→海浪」两套有时差的组合 | 保留相同动作语言，根脉后的追扑衔接稍快 | 连招结束后法环松解，保留 1.4 秒反击窗口 |

玄武的水体有厚度、泡沫、翻卷的浪头和后方退水，伤害只随当前浪头推进，已通过的内部为空。它不生成横跨场地的潮汐矩形。缩甲时普通方向减伤 45%，朝向发亮核心的伤害为 115%；收招期间正常承伤。

白虎第二段的路线不会在第一段起手时预先计算，也不会沿空中的主角位置拐弯。每一段只在各自起手时瞄准一次，随后锁定。普通冲锋兽同样按实际经过的兽身判定，远处路线不会提前造成伤害。

## 暴怒过场

每位首领本局首次降到半血时，播放 1.8 秒的法相近景：聚能、抬头怒啸或展翼、元素爆发、退场。分别使用青龙怒啸、白虎暴怒、朱雀焚天、玄武震怒和天道震怒的实体姿态、色彩与文字。现有实体图集配合位移、压缩、放大和元素纹理完成动作，不额外增加一套大图集。

- 战斗时间、角色移动、弹体、火区、延迟攻击和普通敌人同时冻结；过场本身使用独立的战斗帧步长。
- 清除该首领旧一轮的危险招式，取消旧连招和主角尚未落下的普攻，释放缠足。
- 过场中的暂停按钮可用；设置与切后台也会冻结演出，回来从原进度继续。
- 结束后留 0.65 秒保护和重新起手时间，强化招式仍有完整蓄势动作。
- 半血演出每位首领只触发一次，重开重置，死亡及换境清理状态。

## 美术与验证

蓄势、释放、收招优先于受击姿态，避免连续命中把敌人的起手动作盖住。白虎压肩伏低、囊兽鼓囊聚气、重兽抬爪、朱雀抬翼、玄武缩甲聚水、天道双掌聚光。只在发出攻击后显示实际攻击实体，碰撞和表现共用根脉长度、移动水体位置、浪头宽度和甩尾方向。

运行 `npm run prepare:cocos`、`npm test` 验证玩法及输入。`tools/boss-patterns.test.cjs` 覆盖落地重新瞄准、直线锁定、兽身碰撞、海浪缺口、连续浪、甲片核心、陨火独立锁定、暴怒冻结和暂停点击。正式 Creator 导出的浏览器检查另覆盖两种横屏尺寸下的五位暴怒近景与暂停恢复；只有真正完成 Creator 导出后，才可将其称为正式引擎画面验证。
