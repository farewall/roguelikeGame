# 诛仙剑 · 四剑环绕

诛仙剑作为第三件可选至宝接入开局，实际包含诛仙、戮仙、陷仙、绝仙四把实体飞剑。四把剑各用独立图块，保持90°的轨道间隔，围绕人物运行；前后深度改变剑身大小和人物遮挡顺序。移动时剑阵跟随主角，始终维持四把，不额外生成装饰剑影或地面范围圈。

待机以0.9弧度/秒环绕。基础自动斩击间隔1.2秒、伤害3.2，在原四剑上加速完成一轮覆盖；命中以实际剑刃扫过的位置计算，保留剑阵中央的空隙。同一次回旋对同一敌人最多伤害一次，并只记一次有效普攻、能量与元素反应。火、水、土及伤害、攻速、生命升级沿用现有规则；本次没有增加新的悟道分支，第一境可直接整备前往下一境。

蓄能技「诛仙」点击释放，短暂护身0.45秒，0.12秒后让同样四把剑向外展开并快速回旋0.7秒；最大轨道为普通的1.45倍，每名敌人最多承受一次3.5倍技能伤害。不生成盘古幡飞刃、裂隙或混沌钟波纹。

姿态与碰撞共用 `game/core/swords.js`。轨道是纵向压缩的椭圆，剑身朝外；剑刃在两个模拟时刻之间形成的扫掠区域用于命中判断。释放时快照伤害与元素。暂停、升级和暴怒过场冻结轨道及斩击，跨境清除在途斩击，重开恢复初始四剑。人物在场边的移动边界为最大展开姿态预留空间。
