# 洪荒实体美术更新

以已确认的《洪荒凝形》九种怪物设定及《混沌钟》青铜模型设定图为准，替换游戏运行素材。怪物保留原有定位与六个姿态；混沌钟使用青铜实体贴图，不再用 Graphics 描边模拟钟体。

## 图集与显示

- 小怪 `enemy-actions.png`：1152×768，6列×4行，单帧192×192；初生浊兽、吞灵囊兽、裂界奔兽、镇劫重兽。褶皱、筋肉、自然骨盾和暖色边光形成体积。
- 首领 `chaos-boss-actions.png`：1152×1152，6列×6行，单帧192×192；前五行是四象法相及天道化身，第六行为六种混沌雾纹。实体保持清晰，化雾采用渐变透明边缘。
- 混沌钟 `chaos-bell.png`：768×768，4列×4行，16帧192×192青铜钟体旋转序列，含钟冠、浮雕、厚钟壁、暗色内腔与钟舌。悬于头顶并随战斗时钟自转，颜色使用素材自身明暗，仅辅以微光。镇界只让同一个钟体短暂放大，避免叠出线框钟影。
- 人物与旧法术图集仍按128像素切片，独立于新的怪物及钟体切片；不能统一更改单帧尺寸。

提高了怪物显示尺寸，保持小体无甲炮灰、宽腹喷吐、长肢扑杀、宽厚重兽和大型法相的区别。只改表现尺寸，战斗碰撞、伤害、生成密度与受击/化雾流程沿用上一版。混沌钟上方预留196UI单位的完整显示空间。

## 素材处理与验证

运行素材由 imagegen 按确认的设定生成。缩放后规范化近零/近不透明 alpha，并使用 PaletteAlpha 编码保留透明边缘的连续层次；不使用会丢弃渐变透明度的强制 PNG8 或强制无 alpha 的索引编码。运行素材总量控制在3.5MiB内，为4MiB资源分包留出余量；最终以 Creator 导出预算检查为准。

验证保留普通血量通关、地图内随机单体生成、首领招式和化雾结算；正式 Creator Web 在两种屏幕尺寸下验证九种怪物各生命周期，以及混沌钟实体 Sprite、192像素切片、16帧轮转、不透明显示与居中音波。最后人工抽查实际导出截图。

## 鲜明本色版本

小怪分别采用赤褐血肉/浅腹、孔雀青背/青碧喉囊、靛蓝肌肉/象牙骨片、暗红厚躯/金赭骨盾；四象和天道采用苍青金鳞、黑白虎纹、朱红金羽、墨玉青甲、白玉深蓝。颜色落在实体材质的大色块上，避免统一灰褐调。帧数、角色ID和192像素切片约定保留。首领图集去除生成素材中残留的半透明浅色底，不以浅色矩形覆盖战场。
