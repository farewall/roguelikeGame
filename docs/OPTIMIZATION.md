## 招式与构筑规则

| 首领 | 核心招式 | 二阶段变化 |
| --- | --- | --- |
| 青龙 | 锁定位置的藤蔓生长区 | 追加环形封路 |
| 白虎 | 宽线预警后扑杀 | 从首扑落点发起第二次扑杀 |
| 朱雀 | 分批火羽落点 | 更多落点，追加横向火线 |
| 玄武 | 环形潮汐，命中产生推挤 | 追加水带，蓄力时护甲减伤，收招后恢复正常 |
| 天道 | 轮换四象招式，叠加两侧秩序封锁 | 扩大封锁，使用四象强化招式 |

危险区位置在招式发起时锁定，不在生效前悄悄追随玩家。虚线纹样为蓄力，亮起实线区为生效；圆、环和胶囊直线的渲染尺寸与碰撞几何一致。暂停、切后台、升级与关后记忆冻结战斗，不消耗预警时间。

东皇钟近身一圈清群并轻推敌人；盘古幡射程更远，攻击方向锁定，采用较慢的重击节奏。离火强化灼烧，坎水强化减速，厚土扩大震荡与击退；重复附魔不再变成无差别加伤。水火产生一次范围蒸腾；地火留下持续灼烧区域；地水留下减速泥沼。全三元素时蒸腾与熔流并存。有限升级满级后不再出现无效选项；极限情况下只展示仍有收益的选项。

## 第二轮优化（当前实现）

| 优先级 | 问题 | 当前处理 |
| --- | --- | --- |
| P0 | 不同屏幕相对移速不同 | 玩家、敌人和推挤统一为短边 UI 单位；页面移动与战斗在延迟帧使用相同 50ms 上限 |
| P0 | 第三元素覆盖泥沼控制 | 三元素保留蒸腾，并生成同时造成伤害和减速的熔沼；升级卡提前说明三元效果 |
| P0 | 爆发落点受出生顺序影响 | 普攻保存锁定目标 ID，以实际命中目标的位置确定蒸腾/震荡落点；目标死亡时稳定选取最近存活目标 |
| P1 | 护甲路径不一致 | 直接伤害、灼烧、区域和余波使用同一减伤入口；玄武提示全伤害减免 45% |
| P1 | 元素成长缺少质变 | 火二重传火、四重连锁爆燃；水二重每三击潮涌、四重冰封；地二重延迟余震、四重震慑 |
| P1 | 至宝取舍不足 | 盘古幡改为 205 射程、3.6 伤害；东皇钟每三次有效攻击追加回响。首境后选择回响/护体或清群/破劫路线 |
| P1 | Boss 应对相近 | 白虎扑空后收招易伤 35%；朱雀标记玩家落点并留下持续火区；玄武提示内圈和水带；危险预警加入限频提示音 |
| P1 | 画面混杂 | 法杖/前角/精英印记区分轮廓，头顶职业标记、受伤才显示普通怪血条，隐藏 Boss 重复血条；放大首领体量，移除场地装饰椭圆 |
| P2 | 每局缺少额外决策 | 第二境后从清泉、残卷、精英邀战三类事件抽取其一，玩家在本局恢复、成长和挑战之间选择；不增加局外数值 |
| P2 | 结算缺少复盘 | 展示前三类伤害构成和主要受伤来源，历史记录保留详情；伤害统计剔除过量伤害 |
| P1 | 数据与容量余量 | 精简显示快照，只提交变化字段；不传内部计时；加入主包预算与 32KiB 余量检查，分包规划见 RESOURCES.md |

三元素的伤害与控制共存，回响/余震不递归触发新反应。冰封和震慑对首领减效，阻止移动和新招式，不撤销已经释放的危险区。施法者被灼烧击败后，其危险区在同一步清理，避免死亡后的额外命中。结局文案改为汇聚四象遗力，与当前三元素玩法保持一致。
