# 地图随机单体凝形

每次仅生成一只怪物，位置在可见地图内部独立随机选取，不再使用成群队形或固定边缘入口。普通波和混合波首境间隔0.26～0.38秒，后续每境缩短0.012秒，精英波间隔0.65秒；波次总量提高至基础整局约289只，混合波保留远程和冲锋穿插，精英波每四只穿插一名精英。弱怪仍可被初始至宝轻松击散，奖励0.5灵气。

落点避开人物150短边UI单位，正常随机采样与其他怪物至少间隔60单位（首领110）。位置留出形体显示边距。随机采样最多18次，失败后在地图网格中选择人物安全区外最疏的位置，防止随机数异常或场面拥挤造成死循环；拥挤时只放宽怪物间距，不放宽人物安全距离。无法找到人物安全点时延期重试，不扣待生成数量。

普通怪凝形0.75秒，精英0.95秒，首领1.2秒。前28%时间只见雾气；随后雾旋向中心收束，实体由透明到完整出现。凝形期间原地不动，不施法，不造成碰撞伤害，不被自动攻击选中，不吸收飞刃或钟波命中。角色主动走入凝形落点仍有可见雾气提示。

同屏上限32，普通生成最多31，保留一个首领位置。延迟帧不追补一批怪物；暂停、升级、记忆面板和切后台冻结生成及凝形。死亡后仍按受击、失稳、化雾、回归混沌的流程处理。

测试验证逐只计数、随机内部分布、安全距离、数量上限和首领保留位、凝形交互、暂停与通关。Creator检查脚本新增纯雾阶段的截图与实体完全透明断言；当前只更新源码，不执行正式Creator导出及微信上传。
