# 构筑、探索、动作与续玩

本轮基于 Cocos Creator 3.8.8，保留横屏摇杆、自由探索、自动攻击、四把实体飞剑以及从生物动作读招的规则。

## 诛仙剑

升级新增御剑通灵、游刃掠斩、回锋补漏，各三重。分别改变真实射程与飞行速度、剑锋掠过的弧线与旁击、回剑伤害。升级不会增生第五把剑。

首境后选择一条本局路线，关后界面以三个横向条目展示完整取舍：

| 路线 | 行为与收益 | 代价 |
| --- | --- | --- |
| 游龙御剑 | 掠斩弧线扩大35%，偏好密集敌群，旁击增强 | 单体直击降低14% |
| 追魂剑意 | 优先精英与首领，射程增加40，同轮后续命中保留62%伤害 | 直击降低10%，旁击和掠斩覆盖缩小 |
| 归锋护身 | 回剑从主角身边穿行，有效剑轮归位后护身1.1秒，抵挡一次伤害的35% | 直击降低15% |

剑轮保存出剑时的升级参数。升级、暂停与暴怒不推进剑路；取消空目标不会生成剑，也不会免费蓄能。归锋只有有效命中的剑轮归位后才提供防护。

## 自愿探索事件

每张地图增加一处主题遗迹，位置与补给点分开，并检查可通行连通区域。地图固定地形保持不变，遗迹位置候选与解印方式随本局随机抽取。靠近后通过「查看遗迹」主动打开选择，面板暂停战斗。

可迎战一名守印精英，或献出12元气解印；献血不能致死。也可安全领取4灵气并放弃庇护，或直接离开。挑战奖励必须在守印灵真正死亡后领取，不能重复触发。解印给予一次当前至宝专属提升，并改变本境 Boss 规则；专属升级均满时改为本局伤害增加8%。

| 遗迹 | 本境庇护 |
| --- | --- |
| 青玉封根台 | 青龙每组根脉减少一条 |
| 白骨战魂碑 | 白虎每次扑杀额外蓄势0.18秒，连扑时间同步顺延 |
| 熔心息火炉 | 朱雀余火缩短0.65秒，火浪缺口从170扩大至220单位 |
| 归墟镇海碑 | 浪面缺口扩大，亮甲破势门槛从最大生命6%降至4.5% |
| 天纹遗诏 | 天道敕令额外蓄势0.25秒 |

这些都是可跳过的本局收益，不要求先清完地图再打首领，不增加局外数值成长。

## 敌人配合与主动破势

探索地图中的普通近战会在精英前侧形成护卫，冲锋兽在起手前寻找侧翼。小幅分离让实体不会全部叠在同一点；冲锋一旦锁定，仍遵循原来的直线判定。普通敌人最多同时两类起手，Boss 出招时最多一名普通敌人起手，屏外仍不会发动新的攻击。

战术偏移只用于局部可见的可通行路线；绕障仍共享面向主角的寻路场，不为每个敌人重建整图导航。Boss 寻路继续在普通波次分批准备。镜头缓慢向附近首领偏移，上限横向120、纵向65单位，暂停和暴怒期间一起冻结。

物理攻击、飞刃、飞剑、共鸣及主动技能在青龙盘身期间积累破势，可断开当前组的一条根脉；每组只能断一次。亮甲侧的有效攻击能破开玄武甲片，取消一重尚未释放的海浪，并短暂解除护甲；每套连招仅一次。灼烧等持续伤害不自动积累破势，已释放的海浪不会无故消失。破势通过身体姿态、碎片与简短提示反馈。

## 美术与信息层次

五位首领各增加蓄势末段、落地或收招两张独立实体姿态，共十张；与原姿态及重量过渡衔接。图集全部在开局载入，运行图集约90KB。未使用的旧单张首领立绘移至 `art/boss-motion/reference/` 保存。

降低地表纹理对比，环境物件色彩收敛；树石、人物与飞剑按位置遮挡。常驻构筑面板改为右上「构筑」按钮，打开暂停查看。普通怪只在关键起手或试炼时显示短标签，初始教程与通知缩短，保留摇杆和主动技的清晰显示。

浮字与过场文字使用顶点透明度淡出，不因每帧透明度变化强制重绘字体；世界中的临时精灵与文字采用有上限的复用池，重用时重置旋转、缩放、锚点及文本样式。

## 安全续玩

升级完成、关后奖励、换境、切后台及保存返回时保存本局。主菜单显示「继续修行」。保存生命、升级、路线、经验、能量、波次进度、存活敌人生命、遗迹与补给领取状态、统计和关后奖励状态。

重新进入时恢复进度，清理旧弹体、缠足和未落下的攻击，敌人恢复到可读的中立收招姿态，并给予1.2秒保护。已领取奖励不会再发一次，主动技能能量按保存值恢复。胜败结算清除本局续玩点，手记与历史保留。版本不兼容、损坏或超出大小限制的数据会被忽略，写入失败不会阻止正常游戏。

验证：`npm test`；`npm run prepare:cocos`；正式导出后的 `npm run test:package`、包体预算和 `npm run test:visual`。浏览器检查覆盖两种尺寸的遗迹、详情、三条路线、完整刷新后的续玩，以及原生文字淡出和节点复用；不将这些检查作为微信真机帧率结论。
