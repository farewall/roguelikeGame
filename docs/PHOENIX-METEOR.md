# 朱雀：陨火锁地 → 砸地爆燃 → 余烬焚地

朱雀振翼后逐次发出带火尾的实体陨石。基础三颗、暴怒后五颗，每隔0.32秒单独锁定主角当时的位置，飞行1.1秒后落地。已发出的陨石不继续追踪。地面不绘制目标圆圈，玩家根据抬翼动作和实际飞来的陨石判断走位。

激活后前0.28秒是撞击窗口：爆燃、低伏冲击环、短促碎石飞散，每颗陨石对人物最多结算一次11点撞击伤害。之后是持续燃烧阶段，以焦岩、熔火裂隙和遍布区域内部的低火焰表现；进入火区受到4点灼烧伤害，遵守既有受击无敌间隔。错过撞击后进入火区不会补算撞击伤害。

撞击后的火地保留2.2秒。朱雀随后再次扇翼，推出有170 UI单位真实缺口的移动火浪；旧陨火在火浪到达前依次熄灭，允许沿焦痕回转。火浪以实体火焰表现，地面不显示边界框。来源死亡、换境和重开清理攻击；暂停及弹层冻结全部阶段。半血时收翼浴火，清理旧火区并进入暴怒连招。
