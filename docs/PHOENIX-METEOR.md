# 朱雀：陨火锁地 → 砸地爆燃 → 余烬焚地

将朱雀原来的落地火羽改为带火尾的实体陨石。保留固定落点的圆形预警（基础1.1秒，连续落点每次错开0.13秒），陨石由斜上方向目标加速坠落。落点在预警出现时锁定，不追随人物。

激活后前0.28秒是撞击窗口：爆燃、低伏冲击环、短促碎石飞散，每颗陨石对人物最多结算一次11点撞击伤害。之后是持续燃烧阶段，以焦岩、熔火裂隙和遍布区域内部的低火焰表现；进入火区受到4点灼烧伤害，遵守既有受击无敌间隔。错过撞击后进入火区不会补算撞击伤害。

基础3处落点，二阶段5处，燃烧区持续2.4/3.2秒；火区之间可绕行。二阶段火线保留，视觉改为低矮火焰簇。危险区范围与原圆形/线形碰撞保持一致，边界贯穿预警、撞击与燃烧过程。来源死亡、换境和重开清理危险区；暂停及弹层冻结全部阶段。
