# 青龙藤蔓：中心蔓延与缠足

保留1.05秒落点预警；激活后用0.65秒从落点中心向外生长，主藤弯曲前进，侧枝和叶片依次展开。生长前沿、当前命中半径共用 `game/core/vines.js`，不再整片贴图同时出现。二阶段环形藤蔓从安全内圈边界向外生长，始终保留内圈安全区；天道复用同一套四象藤蔓机制。

角色在激活藤蔓的实际生长范围内且未处于无敌保护时，会被缠足0.85秒；缠足阻止摇杆移动和外力位移，保留自动攻击及主动技能。角色腿部显示藤蔓缠绕与剩余时间，并提示暂时无法移动。

同一片藤蔓每次施放最多缠足一次；触发后2.1秒内不会被其他重叠藤蔓再次缠足。普通伤害仍遵守既有0.9秒受击无敌。缠足不会刷新到永久；效果到期、来源消失、换境与重开会清理状态。设置、升级、记忆弹层及切后台同步冻结生长与禁足时钟。

验证包括：蔓延未抵达时不伤害/缠足、前沿碰撞一致、环形安全洞、禁足阻止移动且允许技能、到期恢复、无敌保护、同片不重复控制、来源死亡释放、暂停与后台恢复，以及完整普通血量通关。Creator导出在两种尺寸下截图检查预警、萌生、蔓延、成形与角色缠足。
