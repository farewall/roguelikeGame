# 密度、升级频率与混沌钟成长初调

## 本轮行为

怪物继续从地图内随机位置逐只聚雾凝形，不恢复成群入口。基础波数量改为14+境数×3，混合波18+境数×3，精英波6+floor((境数-1)/2)，另有每境一名首领；五境基础总量由170提高至289。普通生成间隔首境0.26～0.38秒，每境再减0.012秒；精英波0.65秒，每四名穿插一名精英。同屏上限32和首领预留位置保留，死亡演出及飘字仍有数量上限。

升级需求统一为ceil(5×1.1^(当前等级-1))，控制器与核心模拟共用该函数。整局的选择次数由约8提高到约16。升级仍由三选一产生具体收益，伤害、攻速、生命、元素及新增至宝机制都能进入选择；濒危补给防止生命选项被扩展的池挤掉。

混沌钟常态缩小到上一版70%，悬浮中心下移16UI单位，并同步减少人物上方预留距离。基础半径180，钟域三重后约274；新增叠浪回声和洪钟共振，具体里程碑见[BELL.md](BELL.md)。在途波面保留释放时的范围、共鸣和回响阶位快照。

## 敌人成长

敌人仅在生成时按境数、波次及本境已过时间生成属性，不读取玩家等级、伤害或当前构筑。升级不立刻强化现存敌人。战斗进度的生命修正每25秒提高8%，最多24%；普通波次另有最多8%修正，首领不额外叠加波次系数。

| 定位 | 第一境基础生命 | 第五境基础生命 | 作用 |

| 初生浊兽（实际炮灰） | 2.1 | 3.3 | 继续保留一击清群和成长快感 |

| 镇劫重兽 | 20 | 210 | 多次交锋后击破，并让范围招式有时间施放 |
| 守关首领 | 105 | 780 | 依靠招式与二阶段施压，避免统一堆成海绵 |

首领各境基础生命为105/180/330/520/780。后续伤害系数每境+8%，移速温和增加；攻击预警时长保留，不靠突然缩短反应窗口加难。敌人攻击和接触伤害使用生成时的伤害系数，附魔友方区域不受敌人成长影响。

## 验证与限度

本地核心六组普通血量模拟（两种至宝×种子1/17/42）全部通关，均击破289只、达到17级，即16次升级；核心战斗约337～373秒，同屏峰值16～22。混沌钟的各境首领战斗约19～39秒，盘古幡约16～29秒，随构筑与种子变化。

控制器十二组流程覆盖回声焚音、护念潮鸣、横扫厚土、破劫混合构筑，包含实际升级弹层、整备、技能与结算。新脚本会在合理距离使用已充能技能，验证完整战斗循环；本轮11组胜利、1组第五境落败，四条路线均有通关结果。数据来自确定性模拟，不能替代微信真机手感或帧率测量。

新增范围索敌/碰撞、升级封顶、回响计数与二次回响、在途快照、潮涌范围、选项分配、敌人生成快照、经验与跨境/重开测试。Creator截图脚本补充满钟域场景及钟体尺寸断言。本轮仅提交源码，不执行正式导出或微信试玩上传。
