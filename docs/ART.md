# 美术交付与验收

《开天一念》使用苍古矿彩风格，战斗主体以轮廓、脚点和动作辨认。地表维持低对比，青龙偏草木绿，白虎偏骨金，朱雀有玄岩暖色，玄武以寒蓝为主，天道以灰紫和古金区分。HUD 的常用金色为 #E3C88B、深底为 #14262D。

- 主角、敌人与实体法宝沿用现有 2D 视角。主角基础图集 128 像素单格，足底参考线在第 120 行。败退和胜利用同一角色造型，四方向各一关键姿态。
- 青龙和朱雀作为场景验收样板。优先辨认脚下可走区域与动物起手。能盖住盘古或蓄势敌人的前景地物降低透明度，原有路径和碰撞依据世界几何。
- Boss 的抬爪、缩甲、振翼与聚能承担预警。效果的亮部跟随实际攻击，玄武浪头与缺口使用真实命中参数。
- 透明主体使用 RGBA 或保留渐变透明通道的调色板 PNG。人物、海水和卷浪保留 RGBA。无透明地表使用 JPEG。尺寸由手机画面和生效区域决定。

## 资产清单与导出

统一登记在 [art/catalog.json](../art/catalog.json)。每个条目包含逻辑键、组、相对路径、格式、图像大小与取帧规则。能追溯的源图保存在 `art/`；现有敌人与部分首领的合成原画是制作输入。不上包的旧图与分镜保留在参考目录。

1. 安装 `tools/requirements-art.txt` 中的离线依赖。
2. 运行 `npm run prepare:art` 重建有明确裁切输入的素材及主角结算帧；现有画面全部使用同一份资源清单。
3. 运行 `npm run prepare:cocos`，验证未登记文件、路径、格式、尺寸和越界帧并生成取帧表。
4. 运行正式导出、包体和横屏回归。启动阶段的字标来自 `art/brand/`，由构建脚本复制到 Creator 的微信首屏位置。

镜头内验收以 667×320 小屏与带安全区的 16:9 横屏为下限样本，保持独立的左摇杆与右技能。新增动作或特效先截取实际起手帧与判定帧，在同设备对照局内阅读顺序和帧时间。
