# 美术资源与接入

本次为现有可玩原型补齐水墨矿彩风格的战斗美术，保留首页山河与盘古立绘构图。

## 本地资源

所有运行时资源位于 `miniprogram/images/`，无需图片服务或额外运行依赖。

| 文件 | 用途 |
| --- | --- |
| `titile-bg.png` / `master.png` | 原有首页背景 / 盘古，按实际显示尺寸压缩，保留透明通道 |
| `arena-1.jpg` … `arena-5.jpg` | 初生之野、白骨战场、焚天熔界、归墟寒海、天道之庭 |
| `boss-1.png` … `boss-5.png` | 青龙、白虎、朱雀、玄武、天道透明角色 |
| `enemy-wraith.png` | 普通混沌敌人 |
| `upgrade-*.png` | 开天劲、疾风法、玄黄护体、离火、坎水、厚土六个图标 |
| `ending-dawn.jpg` | 开天结局，新生山河；失败结局复用天道场景 |

场景与怪物为 AI 生成素材，升级图标为项目定制线稿。图集经逐格裁切后以小图交付，运行时不依赖原始图集。原始生成文件保留于本次工作区 `/workspace/generated_images/`，不参与小程序打包。已提交的单图即运行资源。

`tools/prepare-art.cjs` 记录图集的切分、尺寸、压缩及图标制作方法。可用安装了 Sharp 的开发环境运行：

```sh
node tools/prepare-art.cjs /path/to/arena-atlas.png /path/to/creature-atlas.png
```

Sharp 仅用于离线素材处理；小程序本身不需要安装 npm 包。仅运行 `node tools/prepare-art.cjs` 可重新生成六个升级图标。

## 画面规则

- 场景中心保持低对比，边缘承载纹样；暗角保证文字与角色可辨。
- 五境分别使用青绿、骨金、朱红、靛蓝、紫金；HUD 统一古金与墨青。
- 普通敌人与 Boss 使用透明角色图，不再以汉字作为主体。
- 攻击使用光环与斩光，升级使用统一图标，结局增加独立绘景。
- 保留触控区域、战斗数值、自动攻击与升级逻辑；增加 `won` 展示状态区分结局插图。

## 验证范围

Node 语法与已有核心玩法冒烟检查通过。使用本地 Chromium 将 WXML 映射成 HTML 辅助检查首页、青龙战斗、朱雀战斗、升级卡和成功结局，图片均正常加载。该检查不等价于微信小程序编译或真机验证。

发布前仍需在微信开发者工具中核对窄屏/全面屏排版、PNG 边缘、触控与动画性能。本次不上传、提审或发布。正式 CG 分镜、骨骼动画与音效不在本次静态美术资源范围内。
