# 美术资源与接入

本次为现有可玩原型补齐水墨矿彩风格的战斗美术，保留首页山河构图。

## 本地资源

所有运行时图像位于 `cocos-project/assets/game-content/images/`，无需图片服务或额外运行依赖。旧版静态盘古立绘已移至 `art/reference/master.png` 保留，不占主包；当前主角使用 `images/pangu/` 六组动作图。

| 文件 | 用途 |
| --- | --- |
| `titile-bg.png` | 首页山河背景 |
| `arena-1.jpg` … `arena-5.jpg` | 初生之野、白骨战场、焚天熔界、归墟寒海、天道之庭 |
| `boss-1.png` … `boss-5.png` | 青龙、白虎、朱雀、玄武、天道透明角色 |
| `enemy-wraith.png` | 普通混沌敌人 |
| `upgrade-*.png` | 开天劲、疾风法、玄黄护体、离火、坎水、厚土六个图标 |
| `ending-dawn.jpg` | 开天结局，新生山河；失败结局复用天道场景 |

场景与怪物为 AI 生成素材，升级图标为项目定制线稿。图集经逐格裁切后以小图交付，运行时不依赖原始图集。原始生成文件保留于本次工作区 `/workspace/generated_images/`，不参与小游戏打包。已提交的单图即运行资源。

`tools/prepare-art.cjs` 记录图集的切分、尺寸、压缩及图标制作方法。可用安装了 Sharp 的开发环境运行：

```sh
node tools/prepare-art.cjs /path/to/arena-atlas.png /path/to/creature-atlas.png
```

Sharp 仅用于离线素材处理；小游戏运行时不加载 Sharp。仅运行 `node tools/prepare-art.cjs` 可重新生成六个升级图标。

## 画面规则

- 场景中心保持低对比，边缘承载纹样；暗角保证文字与角色可辨。
- 五境分别使用青绿、骨金、朱红、靛蓝、紫金；HUD 统一古金与墨青。
- 普通敌人与 Boss 使用透明角色图，不再以汉字作为主体。
- 攻击使用光环与斩光，升级使用统一图标，结局增加独立绘景。
- 保留触控区域、战斗数值、自动攻击与升级逻辑；增加 `won` 展示状态区分结局插图。

## 验证范围

已用本地 Chromium 运行真实 Eva/Pixi Canvas 场景及生产入口，检查横屏战斗、升级、路线、事件与结算。该检查不等价于微信开发者工具或手机验收。

发布前仍需在微信开发者工具中核对窄屏/全面屏排版、PNG 边缘、触控与动画性能。实际开发上传结果见 GitHub Actions；正式提审与发布不在此次迁移范围内。正式 CG 分镜、骨骼动画与音效不在本次静态美术资源范围内。

## 本轮表现优化

- 敌人预警使用圆、环、胶囊形直线，并与战斗碰撞几何对应；虚线纹样表示蓄力，实线亮区表示生效，除颜色外还保留文字和形状。
- 普通敌人共用游灵图像，以身形比例、颜色、职业标记区分；程序动画补充蓄力、收招、受击闪白与消散。尚未制作独立怪物动作图。
- 钟的音波、幡的扇形、地的裂纹、水火蒸汽使用不同形状；灼烧与减速有独立状态标记。友方熔流、泥沼为低亮度点线边界。
- 血量、Boss 状态、波次目标与升级前后数值均已接入；记忆采用场景配短文，属于过渡呈现，非正式 CG。
- `docs/art-preview.jpg` 是旧版竖屏历史预览，不代表当前界面。运行 `node tools/preview.test.cjs` 生成当前横屏截图。

## 第二轮辨识度与音效

普通敌人加入程序绘制的法杖、冲锋前角与精英印记，职业标签置于头顶；满血普通怪与 Boss 的重复脚下血条隐藏。Boss 显示体量增大，移除会与攻击范围混淆的场地装饰椭圆。新增冰封、破绽、护体、传火与潮涌反馈；三元素友方区域使用熔沼纹样。路线、事件和结算在 667×320 横屏下可见，记忆正文可滚动。

东皇钟、盘古幡与危险预警各有独立的本地合成 WAV。多个预警同帧合并，提示音间隔至少 650 毫秒，遵守音效开关、音量与暂停。独立怪物图像与首领逐帧动画尚未制作。

## 小游戏呈现

运行图像现统一从 `cocos-project/assets/game-content/images/` 加载，主角通过 Pixi 纹理裁切播放。危险区使用 Canvas 几何绘制，菜单与弹层均已迁出 WXML。当前截图见 [战斗](minigame-battle.png) 与 [至宝路线](minigame-path.png)；上述 `current-*.png` 保留为迁移前历史对照。

## 御宝施法素材

新增 `art/pangu-actions/artifact-cast.png`：四向、六列的透明徒手动作源，列依次为两帧待机、两帧行走、蓄势和释放。`tools/prepare-artifact-actions.cjs` 生成 768×512 的运行图，动画映射见 `game/core/artifact-animation.js`。常规战斗、受击和消散均使用该徒手角色，钟/幡以程序绘制随身悬浮，不再复用挥斧攻击。开天成功结局保留原有觉醒图集。新增镇界、裂天与满能提示三段合成音效，遵守音效开关、音量和暂停。

当前图像与声音由 Cocos Bundle 导入，渲染组件为 Sprite、Label、Graphics 与 Mask；原 Canvas 截图保留作历史对照，当前 Creator 画面以 CI 的 cocos-checks 截图为准。
