# Cocos 小游戏资源与性能

Cocos Creator 3.8.8 正式导出运行包。主包负责引擎、脚本与启动场景；图片和声音位于 `assets/game-content/`，微信导出为名为 `game-content` 的分包，通过官方资源 API 加载。

`node tools/package-budget.cjs` 按生成的 `game.json` 分别统计主包、各分包和总量。工程预算为主包及单分包各 4 MiB、预留 64 KiB，总量 20 MiB；最终平台限额与上传压缩体积以微信反馈为准。源码、编辑器缓存、参考图、测试和文档不参与运行包。

游戏使用二维组件，保留 Creator 默认渲染管线的引擎依赖，不把配置清单当作实际裁剪结果。主包和资源分包分别以正式导出统计为准。Cocos 统一驱动帧循环，单帧战斗步长上限 50ms；精灵和文字节点复用，避免逐帧反复启停，实体退出后销毁。

浏览器检查不代表微信低端机帧率。真机需要继续检查高敌人数、朱雀持续火区、三元素叠加、技能爆发和升级恢复时的帧率、长帧、内存、发热、音频和触摸响应。
