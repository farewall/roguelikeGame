# Cocos 小游戏资源与性能

项目使用 Cocos Creator 3.8.8 正式导出。主包放引擎、脚本、启动场景和项目字标。微信横屏小游戏使用本地分包。Web 使用同名资源组做浏览器回归。

| 资源组 | 何时加载 |
|---|---|
| game-shell | 首页所需的山河图。选法宝和手记列表可直接进入 |
| game-content | 主角、通用敌人、法术及地表、升级图标和音效，开始或续玩时加载 |
| game-bell、game-banner、game-swords | 只加载本局选中的法宝 |
| game-realm-1 至 game-realm-5 | 各境首领、补帧、地标、记忆图和对应地表材料。战斗中提前准备下一境 |
| game-tides | 归墟与天道共用的水体、卷浪 |

资源切换未完成时暂停画面推进。退出、换境时先解除节点的纹理绑定，然后回收上一组。下一境预取失败会在正式进入时重试。运行内容来自 [资源清单](../art/catalog.json)，环境和美术工作流见[美术制作](ART.md)。

`node tools/package-budget.cjs` 按正式导出的 `game.json` 分别统计主包、各分包和总量。工程预算为主包及单分包各 4 MiB、预留 64 KiB，总量 20 MiB。平台限制与压缩计数以微信反馈为准。历史参考图、原画、离线工具、测试和文档均在资源边界之外。

场景继续使用 Sprite、Label、Graphics 和 Mask。路网几何按地图缓存，屏外弹体、残影和攻击效果按保守包围盒跳过绘制。单个海浪最多 18 段装饰浪花，水体轮廓仍由实际伤害带和缺口决定。

正式浏览器检查覆盖小屏输入、资源首载和回收、五境、技能和存档。真机还需检查冷/热启动、朱雀余火、玄武叠浪、分裂飞刃及多元素叠加时的长帧、内存、发热和触摸响应。
